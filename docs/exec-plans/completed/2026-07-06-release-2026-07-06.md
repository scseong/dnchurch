- Codex에 배포 위험을 물을 때 "prod가 이번에 처음 나간다"는 전제를 검증 없이 줬다. 실제로는 앱이 dev 프로젝트를 그대로 쓰고 있어(사용자 확인), CHANGE_REQUEST의 배포 순서 지적이 v0.7.0엔 안 맞고 v1.0.0에 해당했다. 배포 위험을 다룰 땐 "앱이 지금 어느 DB를 쓰는가"를 먼저 확인하고 프롬프트 전제로 삼는다.
